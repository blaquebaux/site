Publication controls / Phase 3

DATA AND EVIDENCE POLICY

BLAQUE BAUX separates research from performance and market context from real-time data. A richer interface does not change the evidence class underneath it.

CURRENT RELEASE / RESEARCH ONLY
What the public site may show

Four evidence classes, named plainly.

Simulated research

Backtests, scenario tools, portfolio estimates, and reconstructed sleeve histories. These are research outputs, not account results.

Allowed / disclosed

Research findings

Repository conclusions and validation status, linked to the underlying methods and code record where available.

Allowed / sourced

Public market context

Delayed observations or indicative quotes with source, observation time, freshness state, and limitations.

Allowed / timestamped

Actual performance

Paper, proprietary, or client results require separate evidence, controls, review, and unmistakable labeling before publication.

Blocked / not published

Release rule

No gate opens by implication.

Repository labels such as LIVE describe research and software maturity. They do not mean verified actual performance. Public data does not become real-time because it refreshes frequently. A Phase 3 capability may be enabled only through an explicit, reviewed change to the machine-readable readiness manifest and the corresponding evidence package.
