ANALYSIS v2.0 / company as entry point

From security to economic network

A ticker starts the investigation. It does not end it. Security observations, directional dependencies and consequence paths remain distinct, sourced and point-in-time; sleeve eligibility remains separate from governed assignment.

01 / Security intelligence

Deviation, then context

An anomaly is neutral. Buybacks, debt, capex and liquidity changes can be constructive, adverse or indeterminate depending on funding, valuation, maturities, coverage and operating conditions.

02 / Network intelligence

Direction matters

Customers, suppliers, lenders, competitors and counterparties receive dated edges with source, confidence, materiality and substitutability. Consequences are conditional hypotheses, not automatic contagion.

03 / Sleeve intelligence

Eligible is not assigned

One observation may qualify for several research sleeves. A single assignment exists only when a governed workflow owns the next action.
