ANALYSIS v2.0 / company as entry point

From security to disclosed economic network

A ticker starts the investigation. AN-211 expands only as far as trustworthy sources allow: named counterparties when disclosed, anonymous concentration nodes when identities are withheld, and explicit coverage gaps instead of invented companies.

01 / Security intelligence

Deviation, then context

An anomaly is neutral. Buybacks, debt, capex and liquidity changes can be constructive, adverse or indeterminate depending on funding, valuation, maturities, coverage and operating conditions.

02 / Network intelligence

Disclosure controls the map

Named, anonymous and aggregate nodes are visibly different. Missing identities remain coverage gaps; they are never filled by inference.

03 / Sleeve intelligence

Eligible is not assigned

One observation may qualify for several research sleeves. A single assignment exists only when a governed workflow owns the next action.

How AN-211 handles incomplete disclosure
Verified namedShown only when a primary source identifies the counterparty and direction.
Verified anonymousMaterial concentration is shown even when the filing withholds the company name.
Coverage gapThe missing identity and evidence needed to resolve it are displayed, not guessed.
AAPL currently demonstrates the second state: Apple discloses material customer, carrier and manufacturing-counterparty concentrations, but not the individual identities. Run it to see the real filing-backed map.
