01 / THESIS
The question before the result

Can risk structure survive where prediction does not?

BASE began with a practical problem: a portfolio still has to allocate capital when return forecasts are fragile. The test combined a diversified risk structure with time-series trend, sleeve-level volatility targeting, a deliberate blend, and a governed drawdown brake.

The aim was not to make uncertainty disappear. It was to determine which mechanisms remained useful after the predictive claims were removed.

Research record / locked

The current repository reports an approximately 0.97 Sharpe ratio, 1.30 Sortino ratio, and −11% maximum drawdown for the production profile. These figures are part of the research record, not values generated by this tour.

02 / REJECTION
The result was narrower than the thesis

The forecast failed. The structure did not.

Direct predictive-return tests did not persist out of sample. That matters because a polished model can still be an unstable explanation of the past.

Rejected

Prediction as the durable edge

The tests did not justify treating point return forecasts as a dependable source of portfolio advantage.

Rejected

Complexity as proof

More components did not earn authority by themselves. Each layer had to justify a distinct risk-management role.

Why the rejection stays visible
A keeper is credible only when the claim it replaced remains on the record.
